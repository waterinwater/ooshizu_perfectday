## ⭐ 游戏简介

昭和28年10月X日，初出茅庐的侦探大崎前往轻井泽进行寻人调查，与一名自称为清的绿衣男子偶遇。调查得到初步成果之时，对方突然提出请求：要不要放下工作，跟我一起度过这个下午呢?

根据不同的选择，会遇到完全不同的故事情节。大崎要做出怎样的选择，才能够度过完美的一天呢?

## ✨ 2.0更新内容（2026.5.25）
本游戏初次发布于2025.10.10，发布半年后主创终于爬起来完善了这个游戏：
- [x] **更多图片**：游戏全流程增加了适配故事情节的背景图片，同时，增加了2张CG。
- [x] **更生动的立绘**：重构了立绘逻辑，使得角色在故事中展现出更丰富的表情。此外，增加了角色说话时亮起、不说话是变暗的机制。
- [x] **全程配乐**：增加了符合故事情节的背景音乐及音效。
- [x] **更多演出**：呈现出更丰富的演出效果。
- [x] **优化文件**：使用了更有效率的存储方式，减小了游戏的整体大小。
- [x] **多端游玩**：在原本的Win本地客户端之外增加了网页端。
- [x] **谢幕演出**：增加了结尾的滚动Staff表。
